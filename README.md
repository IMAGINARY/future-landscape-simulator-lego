# future-landscape-simulator-lego
Lego® tiles for the Future Landscape Simulator exhibit

## Contents

- *codes*: Back codes for the tiles.
- *tiles*: Bricklink Studio files.
- *parts*: Part lists for each type of tile in CSV format.
- *instructions*: PDF instructions to build the tiles from the Lego® bricks.
- *renders*: Rendered illustrative images.

The .io files in this repository can be opened with Bricklink's [Studio v3](https://www.bricklink.com/v3/studio/download.page)

All the other files were generated through Studio v3.

### Reused parts

Some parts are reused from the Future Mobility Simulator exhibit:

- industrial
- water
- residential (here referenced as "urban-mid").

### Tile sets

- **set-addon**: Contains only the additional parts required to adapt the existing Future Mobility 
    Simulator to the Future Landscape Simulator exhibit.

## Lego® brick colors

Not all existing Lego® brick colors are available in retail or as easy to find. Also, some have been 
discontinued. Use Bricklink's features to check availability and prices.
